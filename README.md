# Out of Tokens, Mid-Sentence

A single error message for the moment an AI agent runs out of tokens halfway through an answer: it opens with the flat, bureaucratic tone of a real quota error — "token budget exhausted" — and then the twist lands, because the one word that would have settled the whole answer is precisely the word that never got generated, leaving "yes" and "no" equally plausible and the user none the wiser. The program is deterministic and dependency-free: it writes that one line, and nothing else, to `entry.txt` in the output directory.
